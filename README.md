# Menü
Darstellung der Wochenpläne der Bistros Fraunhofer IZI (https://www.cafeteria-leipzig.de/cafeteria-fraunhofer-izi/), Tafelwerk (https://www.tafelwerk-leipzig.de/weeklycard) und Bio-City (https://bistro-biocity.de/wochenkarte) auf einer Website.

Presentation of the weekly menus for the Fraunhofer IZI (https://www.cafeteria-leipzig.de/cafeteria-fraunhofer-izi/), Tafelwerk (https://www.tafelwerk-leipzig.de/weeklycard) and Bio-City (https://bistro-biocity.de/wochenkarte) bistros on a website. All three bistros are located on the old exhibition grounds ("Altes Messegelände") in Leipzig and are highly recommended.
